Einfache Verzweigung: if / else

Eine Verzweigung führt einen Codeblock nur dann aus, wenn eine Bedingung wahr (True) ist. Mit else wird ein alternativer Block für den Fall definiert, dass die Bedingung nicht erfüllt ist.

if <Bedingung>: <Anweisung(en) wenn True> else: <Anweisung(en) wenn False>
Einrückung ist Pflicht: In Python gehören alle Zeilen, die zu einem if- oder else-Block gehören, um 4 Leerzeichen eingerückt. Fehlende oder falsche Einrückung führt zu einem IndentationError.
temperatur = int(input("Temperatur in °C: ")) if temperatur > 35: print("Hitzealarm! Bitte viel trinken.") else: print("Temperatur im normalen Bereich.")

Der else-Zweig ist optional. Ein if ohne else tut bei einer falschen Bedingung einfach nichts.

Mehrfache Verzweigung: if / elif / else

Mit elif (Kurzform für „else if") können mehrere Bedingungen hintereinander geprüft werden. Sobald eine Bedingung True ergibt, wird ihr Block ausgeführt und alle weiteren Bedingungen werden übersprungen.

if <Bedingung 1>: <Anweisungen> elif <Bedingung 2>: <Anweisungen> elif <Bedingung 3>: <Anweisungen> else: <Anweisungen (kein Fall passte)>
punkte = int(input("Punkte (0–100): ")) if punkte >= 90: print("Note: Sehr gut") elif punkte >= 75: print("Note: Gut") elif punkte >= 50: print("Note: Bestanden") else: print("Note: Nicht bestanden")
Reihenfolge zählt! Python prüft die Bedingungen von oben nach unten. Sobald eine zutrifft, werden alle anderen nicht mehr geprüft. Deshalb muss die engste Bedingung zuerst kommen.

Logische Operatoren und geschachtelte Bedingungen

Bedingungen können mit logischen Operatoren verknüpft werden, um komplexe Entscheidungen in einer einzigen Zeile zu formulieren.

OperatorBedeutungBeispielErgebnis
and UND – beide Bedingungen müssen wahr sein x > 0 and x < 10 True, wenn x zwischen 1 und 9
or ODER – mindestens eine Bedingung muss wahr sein x < 0 or x > 100 True, wenn x negativ oder über 100
not NICHT – kehrt den Wahrheitswert um not x == 0 True, wenn x ungleich 0

Ohne logischen Operator (verschachtelt)

if alter >= 18: if alter <= 67: print("Erwerbstätig")

Mit and (kürzer, klarer)

if alter >= 18 and alter <= 67: print("Erwerbstätig")
# Ampelsteuerung mit or farbe = input("Ampelfarbe: ") if farbe == "rot" or farbe == "gelb": print("Bitte warten!") elif farbe == "grün": print("Fahren erlaubt.") else: print("Unbekannte Farbe.")

Was ist das Problem mit diesem Versuch?

Schritt 2 — Die richtige Lösung bauen

Bringe die Blöcke in die korrekte Reihenfolge

Das Programm muss c ebenfalls in den Vergleich einbeziehen. Die korrekte Strategie: a ist das Maximum, wenn es größer oder gleich b und größer oder gleich c ist. Analog für b. Wenn keiner der ersten beiden Fälle zutrifft, muss c das Maximum sein.
