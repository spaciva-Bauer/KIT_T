Die for-Schleife

Eine for-Schleife wiederholt einen Codeblock für jeden Wert in einer Folge. Die häufigste Folge wird mit der Funktion range() erzeugt.

for <Laufvariable> in <Folge>: <Anweisung(en) – werden für jeden Wert ausgeführt>

range() – Zahlenfolgen erzeugen

range() erzeugt eine Zahlenfolge. Der Stopwert ist ausgeschlossen (wie beim Struktogramm: „bis kleiner als").

Aufruf Erzeugte Folge Erklärung
range(5) 0, 1, 2, 3, 4 Start = 0, Stopp = 5 (ausgeschlossen)
range(1, 6) 1, 2, 3, 4, 5 Start = 1, Stopp = 6 (ausgeschlossen)
range(2, 10, 2) 2, 4, 6, 8 Start = 2, Stopp = 10, Schrittweite = 2
range(5, 0, -1) 5, 4, 3, 2, 1 Rückwärts zählen mit Schrittweite −1
# Einmaleins einer Zahl n = int(input("Welche Zahl? ")) for i in range(1, 11): print(n, "x", i, "=", n * i) # Summe der Zahlen 1 bis 100 (Gaußsche Summe) summe = 0 for i in range(1, 101): summe = summe + i print("Summe:", summe) # 5050
Akkumulator-Muster: Eine Variable (hier summe) wird vor der Schleife mit einem Startwert (0) initialisiert und in jedem Schleifendurchlauf aktualisiert. Dieses Muster tritt sehr häufig auf.

Die while-Schleife

Eine while-Schleife wiederholt einen Block, solange eine Bedingung wahr ist. Sie wird eingesetzt, wenn die Anzahl der Durchläufe vorher nicht bekannt ist.

while <Bedingung>: <Anweisung(en)>

for-Schleife – Anzahl bekannt

# Genau 5 Mal wiederholen for i in range(5): print("Hallo")

while-Schleife – Abbruchbedingung

# Solange keine gültige Eingabe eingabe = "" while eingabe != "ja": eingabe = input("Weiter? ")
# Countdown mit while i = 5 while i > 0: print(i) i = i - 1 # i muss sich verändern! print("Start!")
Endlosschleife vermeiden! Wenn die Bedingung einer while-Schleife niemals False wird, läuft das Programm endlos. Achte darauf, dass die Laufvariable im Schleifenkörper immer verändert wird.

break und continue

Mit break und continue kann der Schleifenablauf gezielt beeinflusst werden. Beide Anweisungen funktionieren in for- und while-Schleifen.

break – Schleife sofort verlassen

# Suche erste negative Zahl for i in range(1, 101): z = int(input("Zahl: ")) if z < 0: print("Negativ gefunden!") break # ← verlässt die for-Schleife

continue – Iteration überspringen

# Nur ungerade Zahlen ausgeben for i in range(1, 11): if i % 2 == 0: continue # ← gerade Zahlen überspringen print(i) # Ausgabe: 1 3 5 7 9
Wann welche Schleife?
• for: Anzahl der Wiederholungen ist bekannt (z. B. Einmaleins, Summe bis n).
• while: Abbruchbedingung hängt von Laufzeit-Werten ab (z. B. Benutzereingabe, Annäherungsverfahren).

Knobelaufgabe: FizzBuzz

🧠 Knobelaufgabe

FizzBuzz ist eine klassische Programmieraufgabe: Gib alle Zahlen von 1 bis 20 aus. Aber: Ist die Zahl durch 3 teilbar, gib stattdessen "Fizz" aus. Ist sie durch 5 teilbar, gib "Buzz" aus. Ist sie durch beide teilbar, gib "FizzBuzz" aus.

Schritt 1 — Den naiven Ansatz analysieren

Was stimmt an diesem Versuch nicht?

for zahl in range(1, 21): if zahl % 3 == 0: print("Fizz") if zahl % 5 == 0: print("Buzz") if zahl % 3 != 0 and zahl % 5 != 0: print(zahl)

Was gibt dieser Code für zahl = 15 aus?

Schritt 2 — Die richtige Lösung bauen

Bringe die Blöcke in die korrekte Reihenfolge

Der Schlüssel: Der Fall "FizzBuzz" (teilbar durch 3 und 5) muss zuerst geprüft werden, bevor die einzelnen Fälle geprüft werden. Ansonsten greift einer der früheren elif-Zweige und "FizzBuzz" wird nie ausgegeben.
Bringe die fünf Blöcke in die richtige Reihenfolge. Ein Block gehört nicht dazu!

else: print(zahl)

if zahl % 3 == 0: print("Fizz")
elif zahl % 3 == 0: print("Fizz")
elif zahl % 5 == 0: print("Buzz")
