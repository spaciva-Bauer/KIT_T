Ausgabe mit print()

Die Funktion print() gibt Werte auf dem Bildschirm aus. Sie akzeptiert beliebig viele Argumente, die durch Kommas getrennt werden.

print(*objekte, sep=' ', end='\n')

objekte – beliebig viele Werte, werden mit sep getrennt ausgegeben

sep – Trennzeichen zwischen den Werten (Standard: Leerzeichen)

end – Zeichen am Ende der Ausgabe (Standard: Zeilenumbruch)

# Einfache Ausgaben print("Hallo Welt") # Hallo Welt print(42) # 42 print(3.14, True) # 3.14 True # Mehrere Werte mit sep trennen print("a", "b", "c", sep="-") # a-b-c # Ohne Zeilenumbruch am Ende print("Ergebnis:", end=" ") print(100) # Ergebnis: 100 # Variablen ausgeben name = "Lena" alter = 18 print("Name:", name, "| Alter:", alter) # Name: Lena | Alter: 18
Komma vs. Plus: Mit einem Komma in print() können Werte verschiedener Typen ohne Umwandlung ausgegeben werden (Python fügt automatisch ein Leerzeichen ein). Das Plus dagegen verkettet nur Strings – eine Zahl muss dann erst mit str() umgewandelt werden.

Code

p = 95 print("Punkte:", p) print("Punkte: " + str(p))

Ausgabe (beide identisch)

Punkte: 95
Punkte: 95

Eingabe mit input()

Die Funktion input() hält das Programm an und wartet auf eine Tastatureingabe des Benutzers. Das Ergebnis ist immer ein String (str).

input(aufforderung='')

aufforderung – optionaler Text, der vor der Eingabe angezeigt wird

Rückgabewert – die eingegebene Zeichenkette als str

# Eingabe als String speichern name = input("Dein Name: ") # Eingabe als Zahl: Typumwandlung notwendig! alter = int(input("Dein Alter: ")) preis = float(input("Preis in €: ")) # Verarbeitung und Ausgabe print("Hallo", name + "!") print("In 10 Jahren bist du", alter + 10, "Jahre alt.")
Wichtig: input() gibt immer einen str zurück – auch wenn der Benutzer eine Zahl tippt. Für Rechenoperationen ist int() oder float() zwingend erforderlich.

Kommentare und Programmstruktur

Kommentare erklären den Code und werden von Python nicht ausgeführt. Sie beginnen mit dem Rautenzeichen #.

Einzeilige Kommentare

# Dieses Programm berechnet die Fläche eines Rechtecks laenge = float(input("Länge in m: ")) # Eingabe der Länge breite = float(input("Breite in m: ")) # Eingabe der Breite flaeche = laenge * breite # Berechnung print("Fläche:", flaeche, "m²") # Ausgabe

Guter Programmierstil

Ein gut strukturiertes Programm folgt dem Muster EVA: erst Eingabe, dann Verarbeitung, dann Ausgabe. Leere Zeilen zwischen diesen Blöcken verbessern die Lesbarkeit.

✗ Schlecht lesbar

x=int(input("x:"));y=int(input("y:"));print(x+y)

✓ Gut lesbar (EVA)

# Eingabe x = int(input("Erste Zahl: ")) y = int(input("Zweite Zahl: ")) # Verarbeitung summe = x + y # Ausgabe print("Summe:", summe)
