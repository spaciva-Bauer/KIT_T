Variablen und Zuweisung

Eine Variable ist ein benannter Speicherplatz, in dem ein Wert abgelegt werden kann. In Python wird einer Variablen mit dem Gleichheitszeichen = ein Wert zugewiesen.

Syntax:  variablenname = Wert
Der Name steht links, der Wert rechts. Das = ist kein mathematisches Gleichzeichen, sondern ein Zuweisungsoperator.
# Variablen anlegen und Werte zuweisen vorname = "Lena" alter = 18 groesse = 1.72 aktiv = True # Wert überschreiben – der alte Wert geht verloren alter = 19

Variablennamen dürfen Buchstaben, Ziffern und Unterstriche enthalten, müssen jedoch mit einem Buchstaben oder Unterstrich beginnen. Groß- und Kleinschreibung wird unterschieden (Alter ≠ alter).

Achtung: Python-Schlüsselwörter wie if, for, while, True, False dürfen nicht als Variablennamen verwendet werden.

Die vier Grunddatentypen

Jeder Wert in Python hat einen Datentyp. Python erkennt den Typ automatisch anhand des zugewiesenen Werts (dynamische Typisierung). Mit type() kann der Typ abgefragt werden.

Datentyp Bedeutung Beispielwerte Python-Beispiel
int Ganze Zahl 0, 42, −7 alter = 18
float Dezimalzahl 3.14, −0.5, 1.0 groesse = 1.72
str Zeichenkette (Text) "Hallo", 'Python' name = "Lena"
bool Wahrheitswert True, False aktiv = True
# type() zeigt den Datentyp an x = 42 print(type(x)) # <class 'int'> pi = 3.14159 print(type(pi)) # <class 'float'> gruss = "Hallo!" print(type(gruss)) # <class 'str'>
