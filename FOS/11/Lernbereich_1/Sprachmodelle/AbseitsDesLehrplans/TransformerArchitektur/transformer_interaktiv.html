📌 Tokenisierung
Text in Zahlen umwandeln
Computer verstehen keinen Text. Deshalb wird jedes Wort (oder Wortteil) in eine Zahl (Token-ID) umgewandelt.

Beispiel: "Der Hund schläft" → [3, 7, 12] Alle bekannten Wörter bilden das Vokabular. Unbekannte Wörter werden als [UNK] markiert.

🗺️ Positional Encoding
Position im Satz kodieren
Der Transformer verarbeitet alle Wörter gleichzeitig. Damit er trotzdem weiß, welches Wort wo steht, wird ein Positions-Signal addiert.

Es verwendet Sinus- und Kosinusfunktionen verschiedener Frequenzen: PE(pos, 2i) = sin( pos / 10000^(2i/d) ) PE(pos, 2i+1) = cos( pos / 10000^(2i/d) ) Jede Position hat ein einzigartiges Muster — wie ein Fingerabdruck.

3
👁️ Self-Attention
Das Herzstück des Transformers
Self-Attention beantwortet: „Welche anderen Wörter sind für dieses Wort gerade wichtig?"

Jedes Wort wird in drei Vektoren umgewandelt: Q (Query) — „Wonach suche ich?" K (Key) — „Was habe ich anzubieten?" V (Value) — „Was ist mein Inhalt?" Die Attention-Gewichte werden berechnet: Attention(Q,K,V) = softmax( Q·Kᵀ / √d_k ) · V Hohe Gewichte bedeuten: „Schau genau auf dieses Wort!"

4
👁️👁️ Multi-Head Attention
Mehrere Perspektiven gleichzeitig
Echte Transformers nutzen mehrere Attention-Köpfe gleichzeitig. Jeder Kopf kann auf verschiedene Aspekte achten:
Kopf 1 → Grammatik  |  Kopf 2 → Bedeutung  |  Kopf 3 → Kontext  |  …

Die Ausgaben aller Köpfe werden zusammengeführt (Concatenation + Projektion).
5
🧠 Feed-Forward Netzwerk
Nicht-lineare Verarbeitung
Nach der Attention-Schicht kommt ein einfaches 2-schichtiges neuronales Netzwerk. Es verarbeitet jedes Wort unabhängig:
FFN(x) = ReLU(x·W₁ + b₁)·W₂ + b₂ ReLU ist die Aktivierungsfunktion: ReLU(x) = max(0, x)
Sie bringt Nicht-Linearität ins Modell — ohne sie wäre alles nur lineare Algebra!

6
🔗 Vollständiger Transformer-Block
Alle Bausteine zusammen
Ein vollständiger Block kombiniert alle Teile — mit Skip-Connections (Residualverbindungen) und Layer Normalization: x₁ = LayerNorm(x + MultiHeadAttention(x)) x₂ = LayerNorm(x₁ + FFN(x₁)) In echten Modellen werden viele Blöcke gestapelt:
GPT-2 small: 12 Blöcke  |  GPT-3: 96 Blöcke  |  GPT-4: ~120 Blöcke (geschätzt)
